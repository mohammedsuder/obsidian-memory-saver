**Memory Saver now requires Obsidian 1.13.0 or later.** On older Obsidian versions, Obsidian keeps offering 0.4.1.

### What's new in 0.5.0

- The settings tab uses Obsidian's new settings layout, so **Start-up mode** and **Refresh every** show up in Obsidian's settings search.
- The settings tab is shorter: Lite choices are made in **Manage plugin list** only, where they sit beside each plugin's status. The tab keeps **Reset to suggested** and adds a **Manage plugin list** button.
- Support links: a Ko-fi badge at the bottom of the settings tab, and Obsidian's own **Donate** item in Memory Saver's ⋯ menu in Settings → Community plugins (and on its directory page).
- The refresh slider shows its value next to it, as Obsidian now does for every slider.
- Code clean-up from the community directory review: the plugin no longer bypasses type checks, and it uses Obsidian's current button style for the switch-off confirmation.
- Every release is now checked with the community directory's lint rules before it is built.

No change in how start-up modes work. Your start-up mode and Lite choices carry over.

### Install

- Download `main.js`, `manifest.json` and `styles.css` below into `<your vault>/.obsidian/plugins/memory-saver/`, then switch on **Memory Saver** in Settings → Community plugins.
- Or add `mohammedsuder/obsidian-memory-saver` as a beta plugin in BRAT.

Release files are attested: `gh attestation verify main.js --repo mohammedsuder/obsidian-memory-saver`.

Requires Obsidian 1.13.0 or later, desktop only. Tested on Obsidian 1.14.4.
