**The repository is now `mohammedsuder/obsidian-memory-saver`**, to match the plugin's name. It was `obsidian-plugin-memory-monitor`; old links, git remotes and BRAT entries redirect here.

### What's new in 0.4.1

- The help window's GitHub link points to the renamed repository.
- Release files are attested under the new name, so you can verify them with `gh attestation verify main.js --repo mohammedsuder/obsidian-memory-saver`.

No change in behaviour. If you already run 0.4.0, nothing else to do.

### Install

- Download `main.js`, `manifest.json` and `styles.css` below into `<your vault>/.obsidian/plugins/memory-saver/`, then switch on **Memory Saver** in Settings → Community plugins.
- Or add `mohammedsuder/obsidian-memory-saver` as a beta plugin in BRAT.

Upgrading from Plugin Memory Monitor (0.3.x)? See [Upgrading from 0.3.x](https://github.com/mohammedsuder/obsidian-memory-saver#upgrading-from-03x-plugin-memory-monitor) in the README.

Requires Obsidian 1.8.7 or later, desktop only. Tested on Obsidian 1.14.4.
