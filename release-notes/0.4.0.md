**Plugin Memory Monitor is now Memory Saver.** The plugin was renamed for the Obsidian community directory, and its id changed from `plugin-monitor` to `memory-saver`.

Memory Saver helps Obsidian use less memory on resource-constrained machines: each device chooses which community plugins load at start-up, so the rest never load at all.

### What's new in 0.4.0

- New name and id: **Memory Saver** (`memory-saver`).
- Support me on Ko-fi badge in the help window.
- Release files are now built by GitHub Actions from the tagged source, with build provenance attestations, so you can verify them with `gh attestation verify main.js --repo mohammedsuder/obsidian-plugin-memory-monitor` (the repository's name when 0.4.0 was released; it is now `mohammedsuder/obsidian-memory-saver`).

### Upgrading from 0.3.x

Because the id changed, Obsidian treats Memory Saver as a new plugin:

1. Install 0.4.0 into `<your vault>/.obsidian/plugins/memory-saver/` and switch on **Memory Saver** in Settings → Community plugins.
2. Switch off and delete **Plugin Memory Monitor**.
3. Your start-up mode and Lite choices carry over on each device. If you use Lite or Extreme, choose it once more in the popup so Memory Saver moves to the top of your plugin list.

### Install

- Download `main.js`, `manifest.json` and `styles.css` below into `<your vault>/.obsidian/plugins/memory-saver/`, then switch on **Memory Saver** in Settings → Community plugins.
- Or add `mohammedsuder/obsidian-memory-saver` as a beta plugin in BRAT.

Requires Obsidian 1.8.7 or later, desktop only. Tested on Obsidian 1.14.4.
