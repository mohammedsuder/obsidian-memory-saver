**Lite now starts from your own plugins.** On a first install, Lite includes every plugin that is switched on at that moment, so a Lite start loads the same as Standard until you untick plugins. Earlier versions started Lite from a fixed list of suggested plugins, which loaded nothing in vaults that had none of them.

### What's new in 0.6.0

- First install: Lite starts as every plugin that is switched on. Untick the ones you do not need every day under 🪶 Lite in **Manage plugin list**, then start in Lite.
- Upgrading keeps your Lite choices. If they were never saved (you kept the old suggested list), the list this device was using is saved as it is.
- Settings → Memory Saver: **Reset to suggested** is now **Reset to all switched on**, and it asks first, because it replaces your Lite choices on every device.

No change in how start-up modes work.

### Install

- In Obsidian: Settings → Community plugins → Browse, search for **Memory Saver**, then Install and Enable.
- Or download `main.js`, `manifest.json` and `styles.css` below into `<your vault>/.obsidian/plugins/memory-saver/`, then switch on **Memory Saver** in Settings → Community plugins.

Release files are attested: `gh attestation verify main.js --repo mohammedsuder/obsidian-memory-saver`.

Requires Obsidian 1.13.0 or later, desktop only. Tested on Obsidian 1.14.4.
